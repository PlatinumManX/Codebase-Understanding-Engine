Architecture Overview

CodeMap AI is built on a distributed graph-processing engine designed to handle massive codebases with millions of lines of code. By combining Abstract Syntax Tree (AST) analysis with a high-performance vector database, we enable real-time semantic search and execution flow tracing.

Core Components

  • Static Analysis Layer: Extracts structural data using tree-sitter based parsers for multi-language support.
  • Relational Graph Store: Maps dependencies between functions, classes, and modules in a neo4j-optimized format.
  • LLM Context Manager: Dynamically prunes irrelevant code blocks to fit high-density logic into token windows.
warning

Critical Configuration

Ensure your codemap.json file is located in the root directory before running the indexing command. Failure to do so will result in a recursive scan skip.

Integration Example

Use the following SDK snippet to initialize the graph explorer within your CI/CD pipeline:

javascript / node.js 

import { CodeMapClient } from '@codemap/sdk';

// Initialize engine with secure credentials
const client = new CodeMapClient({
  apiKey: process.env.CODEMAP_API_KEY,
  projectId: 'main-service-v2'
});

async function analyzeFlow() {
  const flow = await client.flow.trace({
    entryPoint: 'src/index.ts',
    depth: 5
  });
  
  console.log(`Engineered ${flow.nodes.length} graph nodes.`);
}
